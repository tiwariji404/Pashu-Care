# 🐄 Safe Cow \n\n**Award-Winning Hackathon Prototype**\n\nSafe Cow is a comprehensive, multi-platform Emergency SOS and Management Solution built for citizen safety, animal welfare, and municipal efficiency.\n\nOur platform integrates **Citizens, Volunteers, Vets, and Government Officials** into a single seamless pipeline to address issues like wandering cattle, disease outbreaks, and unexpected accidents on city streets.\n\n---\n\n## 🌟 Problem Statement\nStray cattle on roads create severe traffic hazards, lead to unfortunate accidents, and pose disease risks (e.g., Lumpy Skin Disease outbreaks). There is no centralized system for citizens to easily report an injured or stray animal, nor a coordinated dashboard for authorities and shelters (Gaushalas) to take immediate action. \n\n## 💡 The Solution (Safe Cow)\nA real-time unified dashboard and mobile-optimized web app that utilizes a centralized data repository, QR tagging, and SOS features to instantly bridge the gap between reporters and responders.\n\n### Key Features\n- 🚨 **Universal SOS System:** 1-click reporting for \"Injured Animal\" or \"Disease Outbreak\". Immediately routes coordinates to the nearest shelter or vet.\n- 📱 **QR Scanning & Tagging:** On-field volunteers use built-in QR scanners to tag cattle. Real-time logging of cattle data (owner details, health records).\n- 🗺️ **Live Dashboards:** Dedicated views for Admins, Gaushala Managers, Patrolling Squads, and Tagging Agents. \n- 🏥 **Automated Alerting:** Owner notifications and rescue coordination happen instantaneously over the application state.\n- 🌐 **Offline/Online Resilience:** A PWA-grade interface ensures fast operation in rural or low-connectivity zones.\n\n## 🛠️ Tech Stack\n- **Frontend:** React 19, Vite, Tailwind-like modular CSS, Zustand (State Management)\n- **Backend:** Node.js, Express.js\n- **Deployment:** Docker & Docker Compose\n- **Peripherals:** HTML5-QRCode Scanner integration \n\n---\n\n## 🚀 Quick Start Guide (For Judges)\n\nWe have completely Dockerized the application for effortless testing.\n\n### Prerequisites\n- Make sure you have [Docker](https://www.docker.com/) installed on your machine.\n\n### Run the App\nSimply run the following command in the root directory:\n\n```bash\ndocker-compose up --build\n```\n\n### Access\n- **Frontend Interface:** `http://localhost:5173`\n- **Backend API:** `http://localhost:3001/api/state`\n\n#### Testing Credentials\nWe have heavily populated mock data to demonstrate full capabilities. Try logging in with the default Admin credential (in the auth portal) or use the different specialized dashboards by visiting their respective routes in the app (e.g., `/dashboard`, `/admin`, etc.).\n\n---\n\n*Built for solving real-world challenges, one tag at a time.*
